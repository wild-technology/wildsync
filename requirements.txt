# Wild Sync - Python packages imported beyond the standard library.
#
# Derived from the imports in every .py file under rig/ and deploy/, including
# the tests. Nothing is pinned here: on the rig most of these are the
# distribution's own apt packages (listed per section), whose version is
# whatever Ubuntu ships for that release (Jetson: JetPack 6 / Ubuntu 22.04;
# camera nodes: Ubuntu 24.04). On a macOS or other development host, install
# the pip set into a venv with
#
#     python3 -m venv ~/rig/venv && ~/rig/venv/bin/python3 -m pip install -r requirements.txt
#
# (Homebrew's Python is externally managed, PEP 668, and refuses a global pip
# install; docs/INSTALL.md section 3a is the Mac host procedure, and its launchd
# agent runs that venv's interpreter.)
#
# Policy: docs/PROTOCOL.md ("Deliverables & boundaries") specifies the Python
# standard library only for the services, with pyserial the one permitted
# exception. Everything else below is imported guardedly or lazily, and each
# entry says what stops working without it. The C++ daemon (ilxctl) has no
# Python dependencies; its own third-party components are the Sony Camera
# Remote SDK and third_party/httplib.h (see THIRD_PARTY_NOTICES.md).

# ---------------------------------------------------------------------------
# Host daemon - rigd (rig/rigd.py, rig/run.py, rig/nav.py)
#   Jetson: apt, installed by `deploy/deploy.sh jetson`
#           (python3-serial, python3-pil).
#   macOS / development host: pip, from this file.
# ---------------------------------------------------------------------------

# pyserial - imported as `serial` by rig/nav.py, which reads the iKonvert
# NMEA 2000 gateway on its serial port, and by the serial transports of
# rig/imu_yb.py and rig/imu_olive.py. Without it rigd still runs and the
# flight log carries empty nav columns.
pyserial

# Pillow - imported as `PIL` by rig/run.py for the EXIF fallback that supplies
# a frame's capture instant when it has no GPIO edge. rigd starts without it
# but warns at run start, and such a frame then takes the command time.
# Also used by rig/stereo_check.py, the icon generators in deploy/icons/, and
# the test fixtures in rig/tests/fakenode.py.
Pillow

# ---------------------------------------------------------------------------
# Calibration and VSLAM tools - rig/rigcal.py (the stereo checkerboard
# calibration behind rigd's Calib tab), rig/vslam.py, rig/stereo_check.py, and
# rig/tests/rigcal_selftest.py, rig/tests/vslam_selftest.py
#   Jetson: apt, installed by `deploy/deploy.sh jetson`
#           (python3-numpy, python3-opencv).
#   macOS / development host: pip, from this file.
# rigcal and vslam import both lazily and report them unavailable when they are
# missing; the rest of rigd is unaffected. stereo_check imports them at the top
# and cannot run without them.
# ---------------------------------------------------------------------------
numpy
opencv-python-headless        # imported as cv2

# ---------------------------------------------------------------------------
# Node service - piagent (rig/piagent.py): every camera Pi, and the Jetson in
# its strobe role. Linux only; not installed with pip.
#   Camera nodes: apt, installed by `deploy/deploy.sh provision`
#                 (python3-libgpiod).
#   Jetson strobe role: apt, installed by `deploy/deploy.sh strobe`
#                 (python3-libgpiod).
# ---------------------------------------------------------------------------

# gpiod - in-process GPIO for the FOCUS and TRIGGER lines (class _LineDriver in
# rig/piagent.py) and for the strobe line. The code is written against the
# libgpiod v1.6.3 Python API, which docs/PROTOCOL.md pins and which is what
# Ubuntu 24.04 packages as python3-libgpiod. It is left out of the pip set on
# purpose: install the distribution package on the target. Without it piagent
# falls back to one `gpioset` subprocess per edge, which costs milliseconds of
# trigger timing (README, "How synchronised capture works").
#
# pyserial on a node is needed only when that node's IMU is read over a serial
# port (WILDSYNC_NODE_IMU=yb, or an olive:/dev/ttyACM0 spec). The default Olive
# path goes through olive-bridge over UDP and uses the standard library only.
# `deploy.sh provision` does not install python3-serial; add it by hand on a
# node that needs it.
