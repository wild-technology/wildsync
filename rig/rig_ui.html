Set on the body only

storeDest and pcsave report enableFlag=DisplayOnly on these bodies: they cannot be set over USB and must be changed in the camera's own menu, per body. Shown here so you can check them, never to pretend this panel can set them.

Lens — per camera, never fleet-applied

Focus and zoom POSITION stay per-camera until lens encoder parity between the two bodies is measured (docs/future-tests.md §1): the same number may not mean the same optical state on both, and a silent focus mismatch changes the interior orientation of the pair. The readings are here so a mismatch is at least visible — compare them after any body power-cycle, because nothing re-asserts these.
